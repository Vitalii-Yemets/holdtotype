# Security policy

## Supported versions

Only the latest release gets security fixes. Before reporting, please check that the problem is still there in the latest version on the [releases page](https://github.com/Vitalii-Yemets/holdtotype/releases).

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately on GitHub (the Security tab of this repository, Report a vulnerability) or write to holdtotype@outlook.com, and include:

- the HoldToType version, shown at the bottom right of the settings window;
- what an attacker can do, and under which conditions;
- the steps to reproduce it, or a proof of concept.

I will answer by email and keep the report private until a fix is released.
